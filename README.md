# User Guide: Data Preprocessing and Analysis Scripts

This document provides a guide for using four Python scripts developed for data preprocessing, geocoding, spatial and temporal data clustering, and characterization of the generated clusters. The workflow is sequential: the first script prepares the data, the second adds geocoding information, the third performs the clustering, and the fourth characterizes the generated clusters.

### Script Descriptions

1. **01_pre_process.py**

   This script is responsible for the initial preprocessing of the input CSV file.

* Main function: `preprocess_data(input_csv)`

  * Description: Renames columns, converts the date column to the datetime format, and applies filters to remove records with low spatial accuracy.
  * Parameters: `input_csv` (path to the input CSV file).
  * Output: A new CSV file is created in the `data` folder containing the cleaned and filtered records.

2. **02_pre_geocode.py**

   This script assigns geocodes to the records using IBGE shapefiles.

   This script was used only to generate the datasets for the experiments involving non-human primates (NHPs), due to the need to geocode the records for comparison with the Ministry of Health (MoH) database of confirmed yellow fever (YF) cases.

   This script was not used in the experiments involving bird records (E-Vigilância paper), since there was no need to generate geocodes for data validation purposes.

* Main function: `geocode_data(input_csv, output_csv_7d, output_csv_6d, mun_shp, uf_shp)`

  * Description: Performs a spatial join between the record coordinates and the municipality and state polygons from the IBGE shapefiles. It adds columns for the geocode, municipality, and state (UF). The script generates two output files: one with 7-digit geocodes and another with 6-digit geocodes.
  * Parameters:

    * `input_csv`: Path to the input CSV file (the file generated by the previous script).
    * `output_csv_7d`: Path for saving the file with 7-digit geocodes.
    * `output_csv_6d`: Path for saving the file with 6-digit geocodes.
    * `mun_shp`: Path to the municipality shapefile.
    * `uf_shp`: Path to the state shapefile.
  * Output: Two CSV files are created in the `data_plos` folder:

    * `...filtrado_limpo_geocode.csv` (with 7-digit geocodes)
    * `...filtrado_limpo_geocode_6d.csv` (with 6-digit geocodes)

3. **03_clustering.py**

   This script performs clustering of records based on spatial and temporal proximity using the DBSCAN algorithm.

* Main function: `cluster_records(input_csv, output_csv, matrix_output_folder, time_limit, distance_limit)`

  * Description: Calculates distance and time matrices between all pairs of records. It then normalizes and combines these matrices to create a total distance matrix. DBSCAN is run twice with different parameters (`min_samples=1` and `min_samples=2`) to create two cluster columns (`Cluster1` and `Cluster2`).
  * Parameters:

    * `input_csv`: Path to the input file (the file generated by the previous script).
    * `output_csv`: Path for saving the output CSV file containing the cluster assignments.
    * `matrix_output_folder`: Folder for saving the distance, time, and total distance matrices.
    * `time_limit`: Time limit, in days, for considering records to be temporally close.
    * `distance_limit`: Distance limit, in km, for considering records to be spatially close.
  * Output:

    * A new CSV file, `clusters_30d_1km.csv`, is created in the `data` folder with the clustering results.
    * The distance, time, and total distance matrices are saved as CSV files in the `data_plos/distance_matrix` folder.

4. **04_characterization.py**

   This script is responsible for characterizing the data clusters generated by `03_clustering.py`. It takes as input the CSV file containing the records and their respective cluster assignments (`Cluster1` and `Cluster2`) and produces a new CSV file with summary attributes for each cluster.

* Main function: `calculate_cluster_characteristics(input_csv, output_csv)`

  * Description: The algorithm performs the following steps for each cluster:

    * **Data Reading and Preparation:** Reads the input CSV file and converts the date column to the datetime format.
    * **Data Standardization:** Standardizes the values in the `d_classificacao` and `d_doenca` columns to ensure consistency.
    * **Characteristic Calculation:** Groups the data by cluster (`Cluster1`) and calculates several metrics, including:

      * The total number of animals.
      * The number of records corresponding to `dead` and `alive` animals.
      * The number of records for each behavior type (`Normal`, `Sick`, `Strange`, `Aggressive`).
      * The time span (in days) between the first and last observation in the cluster.
      * The spatial extent (in km), calculated as the geodesic distance between the two farthest points within the cluster.
      * The presence or absence of disease records or confirmed cases.
    * **Frequency and Percentage Calculations:** Calculates the frequency of records and the frequency of animals per day, as well as the percentage of deaths and other behaviors relative to the total number of animals.
  * Output:

    * The final DataFrame, containing one row for each cluster with all calculated characteristics, is saved as a new CSV file.
